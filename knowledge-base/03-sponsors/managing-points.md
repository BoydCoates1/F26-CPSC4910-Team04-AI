# Managing Driver Points

## Who can change points?
Authorized sponsor users can add or deduct points from drivers associated with their sponsor. Drivers can review their point balance and history but cannot award themselves points.

## Making a point adjustment
1. Sign in as a sponsor user.
2. Open the driver-management area.
3. Select the driver.
4. Open the points or point-adjustment action.
5. Enter the number of points to add or deduct.
6. Enter a clear reason for the adjustment.
7. Review the change and confirm it.

The project requirements state that every point change must have a reason. Do not submit an unexplained adjustment.

## Point value
The specified default is $0.01 per point. Sponsors may set their own dollar value per point. The project work items also mention a possible maximum point value or budget control; confirm the live settings before relying on such limits.

## Reviewing point history
Sponsors should be able to review participating drivers' point status and point changes. A useful history includes the date, number of points, reason, and sponsor user who made the change, where those details are available.

## Good practice
- Verify the correct driver before changing points.
- Use a specific, factual reason.
- Check the amount before confirming.
- Review the resulting balance or history.
- Never share or change a driver's password to perform a point adjustment.
