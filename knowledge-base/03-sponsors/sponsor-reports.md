# Sponsor Reports

## Available sponsor reports
The project requirements specify two sponsor report categories:

1. **Driver Point Tracking**
2. **Audit Log**

Exact report layouts and filters should be confirmed in the live website.

## Driver Point Tracking
This report is intended to show point activity for:
- All drivers associated with the sponsor, or
- One selected driver.

The report should support a date range and display:
- Driver name.
- Total points.
- Point changes.
- Date of each point change.
- Name of the sponsor user who made the change.
- Reason for the point change.

### Running the report
1. Sign in as a sponsor user.
2. Open the sponsor reports area.
3. Select Driver Point Tracking.
4. Choose all drivers or an individual driver.
5. Select the date range.
6. Run or refresh the report.
7. Review the results and use the download option if available.

## Sponsor Audit Log
The sponsor audit report is restricted to the sponsor's own drivers and relevant sponsor data. The project requirements specify:
- A date-range filter.
- An audit-category filter.
- Audit categories based on the significant events recorded by the program, such as application decisions, point changes, password changes, and login attempts.

A sponsor should not be able to use this report to inspect another sponsor's drivers.

## Exporting reports
The project requires reports to be visually readable and downloadable as CSV files. A CSV is useful for further analysis, but it is not the visually formatted report itself.
