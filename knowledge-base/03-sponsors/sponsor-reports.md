# Sponsor Reports

## Available sponsor reports
The sponsor dashboard provides a **Report** quick action that opens **Driver Point Tracking**. The report displays driver point activity and provides driver and date filters.

### Running the report
1. Sign in as a sponsor user and open **Dashboard**.
2. Choose **Report**.
3. Select the driver and date range using the available filters.
4. Review the displayed results.

The project requirements describe a sponsor audit report, but do not assume it is available to sponsor users unless it appears in the current website. Do not promise a download/export option unless one is visible.

## Interpreting results
Check the selected date range and driver filter before drawing conclusions. The report only reflects the data and filters shown.
