# Viewing the Website as Another User

## View as another user
The administrator dashboard includes a **View as** function. The interface displays a banner while this mode is active and provides a way to return to the administrator account. It is read-only; do not describe it as a way to perform actions as the represented user.

## Important permission boundaries
## Using impersonation
Before using this feature:
1. Use **View as** only for an authorized support or administrative purpose.
2. Select the correct user and confirm the interface displays the view-as banner.
3. Use the read-only view to investigate what the user sees.
4. Use the banner's return control to go back to the administrator account.

## Safety and accountability
Never ask a user for their password. The sponsor dashboard may have a separate driver-view feature; do not assume it works the same way as administrator **View as**.
