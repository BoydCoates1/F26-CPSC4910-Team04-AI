# Managing Users

## Overview
Administrators can use the account-management interface to search and manage accounts. Available actions depend on the selected account and controls shown.

## Finding a user
1. Sign in as an administrator and open **Dashboard**.
2. Choose **Manage Accounts**, or select **Accounts** in the main navigation.
3. Search or filter accounts, then select the relevant account.
4. Review the information and available actions.

## Updating a user
Use only the account actions available in the selected account's interface. Review any confirmation before saving or changing account status.

Changes to account information can affect the user's access or ability to use the program. Verify the correct user before saving.

## Adding a user
Account creation and invitations differ by role. Sponsor users can invite another sponsor user from the sponsor dashboard's **Sponsors** section. Do not claim administrators can add every role or prescribe fields unless the current form provides that action. **Applications** is a separate dashboard action for reviewing driver and sponsor applications.

## Privacy and access
Only access personal information when necessary for administration. Do not share user details in public channels or provide them to an unrelated person.

## Password help
Administrators should direct users to the approved password-reset process. Do not ask users to disclose their existing password.
