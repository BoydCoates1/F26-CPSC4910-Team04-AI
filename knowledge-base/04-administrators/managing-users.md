# Managing Users

## Overview
Administrators are intended to be able to review and update:
- Driver users.
- Sponsor users.
- Administrator users.

Administrators can also add new drivers, sponsor users, and administrators.

## Finding a user
1. Sign in as an administrator.
2. Open the user-management area.
3. Choose the relevant user category or use the available search.
4. Select the user and review the information displayed.

[CONFIRM IN WEBSITE: Search fields, filters, and exact user categories.]

## Updating a user
1. Open the user's record.
2. Review the information before making changes.
3. Edit only the fields you are authorized to update.
4. Save and confirm the result.

Changes to account information can affect the user's access or ability to use the program. Verify the correct user before saving.

## Adding a user
Use the appropriate add-user action and complete the fields requested by the website. Confirm the user's role and, for a driver, the correct sponsor affiliation.

[CONFIRM IN WEBSITE: Required fields, password/invitation workflow, and whether a driver must have an approved sponsor application before being added.]

## Privacy and access
Only access personal information when necessary for administration. Do not share user details in public channels or provide them to an unrelated person.

## Password help
Administrators should direct users to the approved password-reset process. Do not ask users to disclose their existing password.
