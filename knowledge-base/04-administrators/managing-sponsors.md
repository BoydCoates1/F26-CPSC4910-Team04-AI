# Managing Sponsors

## Sponsor and user administration
Administrators use **Dashboard** → **Manage Accounts** or **Accounts** to search and manage accounts. The public registration form does not offer administrator registration. Do not claim there is a separate sponsor-editing workflow unless it is visible in the account controls.

Sponsor users can manage their own sponsor-specific driver, catalog, and report areas from their dashboard. Only use administrative controls that are visible and authorized for the account.

For applications, use the dashboard's **Applications** action. For sponsor user invitations, see `../03-sponsors/sponsor-accounts.md`.
