# Administrator Reports

## Overview
The project requirements specify the following administrator reports:
- Sales by Sponsor.
- Sales by Driver.
- Sponsor Invoice.
- Audit Log.

Reports should be visually appealing and downloadable as CSV files. Confirm the formats currently available in the live website.

## Sales by Sponsor
The report should allow the administrator to select:
- All sponsors, or
- One individual sponsor.
- A date range.
- Detailed or summary view.

Use the filters, run the report, and verify the selected sponsor and date range before interpreting the results.

## Sales by Driver
The report should allow:
- All sponsors or one sponsor.
- For an individual sponsor, all drivers or one driver.
- A date range.
- Detailed or summary view.

The exact meaning of a sale, date field, and summary calculation should follow the report labels and program accounting rules.

## Sponsor Invoice
The requirements specify one invoice per sponsor. The invoice should:
- Be filterable by all sponsors or one sponsor.
- Use a selected date range.
- Summarize purchases by driver during that period.
- Show the fee generated by each driver.
- Show the total fee due for the sponsor.

The project backstory says the service provider earns 1% of total sales generated by the system once it is in production. Do not calculate or promise a fee outside the invoice's defined calculation and selected reporting period.

## Audit Log
Administrators should be able to filter audit logs by:
- Date range.
- All sponsors or one sponsor.
- Audit-log category.

The project brief identifies significant events including driver application decisions, point changes, password changes, and login attempts.

## Running a report
1. Sign in as an administrator.
2. Open the reports area.
3. Select the report.
4. Choose the available filters.
5. Run the report.
6. Review the displayed results.
7. Download the CSV if needed.
