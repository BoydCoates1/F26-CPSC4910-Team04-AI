# Troubleshooting Guide

## General steps
When something does not work:
1. Read the full message shown by the website.
2. Check that you are signed in to the correct account.
3. Refresh the page and retry once.
4. Check required fields and values for missing or invalid information.
5. Confirm that the action is available to your role.
6. If the problem persists, contact the appropriate sponsor administrator or program support.

## Error while saving a profile
- Check that required fields are completed.
- Review any validation message.
- Confirm that the information uses the format requested by the form.
- Retry after correcting the highlighted fields.

## Error while changing points
- Confirm that the correct driver is selected.
- Check that the point amount is valid.
- Enter a reason if the form requires one.
- Review the change before confirming.
- If the adjustment appears twice or the balance is unexpected, stop and ask an authorized administrator to investigate.

## Error while adding a product
- Check whether the product is still available from the provider.
- Confirm that it meets the program's catalog content restrictions.
- Check whether it is already in the sponsor catalog.
- Retry only after reviewing the message.

## Error while placing an order
- Refresh the product details to obtain current price and availability.
- Confirm the driver's available point balance.
- Check all required checkout information.
- Do not repeatedly submit if the website may already have created an order. First check order history.

## Report appears empty or incorrect
- Verify the date range.
- Verify the selected sponsor and driver filters.
- Check the selected report category and detailed/summary view.
- Confirm whether the report includes the dates at the beginning and end of the selected range.

## When to escalate
Escalate to program support or an authorized administrator if:
- You suspect unauthorized account access.
- A point change or order appears duplicated.
- A user can see another sponsor's or driver's private information.
- An important action cannot be completed after the general checks.
- The website displays an error that prevents normal use.

When reporting an issue, include the page, action, approximate time, and exact non-sensitive error text. Never include passwords, reset tokens, or secrets.
