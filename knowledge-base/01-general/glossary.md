# Glossary

| Term | Meaning |
|---|---|
| Admin / Administrator | A platform-level user who can manage users and sponsors and access administrative reports and audit information. |
| Application | A driver's request to join or become affiliated with a sponsor. |
| Audit log | A record of important actions or changes, such as point adjustments, application decisions, password changes, and login attempts. |
| Catalog | The set of reward products made available by a sponsor. |
| Driver | A program participant affiliated with one sponsor and able to earn and redeem points. |
| Driver application | A driver's request for a sponsor to accept them into its program. |
| Driver points | Program points credited to a driver's account and used for eligible catalog purchases. |
| Impersonation / Assume identity | An authorized admin or sponsor user viewing and operating the website as another user, within the permissions allowed by the platform. |
| Order / Purchase | A driver's request to redeem points for a product. The exact order lifecycle and cancellation rules depend on the website. |
| Point adjustment | An addition or deduction of points, generally made by an authorized sponsor user and accompanied by a reason. |
| Point balance | The current number of points available to the driver, subject to pending or completed transactions as shown by the website. |
| Point value | The dollar value assigned to each program point by a sponsor. The specified default is $0.01 per point. |
| Sponsor | A company that participates in the program, manages its drivers, awards points, and maintains its own product catalog. |
| Sponsor user | A person with permission to manage a sponsor's program information and drivers. A sponsor may have multiple sponsor users. |
| Third-party provider | An external company or service that supplies product information and fulfills or delivers products. |

## Wording guidance
Use “points” rather than “money” when describing a driver's reward balance. Do not imply that points are transferable, refundable, or redeemable for cash unless the live program terms explicitly say so.
