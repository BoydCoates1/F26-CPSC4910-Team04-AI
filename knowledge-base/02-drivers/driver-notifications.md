# Driver Notifications

## Notification types shown by the application
Driver notification preferences include:

| Event | Can the driver disable it? |
|---|---|
| Points activity | Preference is configurable. |
| Order updates | Preference is configurable. |
| Applications | Preference is configurable. This category includes application/removal notifications. |
| Announcements | Preference is configurable. |

## Managing preferences
1. Sign in and open the profile menu by selecting your username.
2. Choose **Settings**, then **Notification settings**. You can also open **Notifications** from the bell and follow its settings link.
3. Review the available categories and change the preferences you want.

## Important exception
The project brief says that a removal alert should not be disableable. However, the current interface groups application and removal notifications under the configurable **Applications** preference. Do not promise that removal notifications are enforced when this preference is disabled; the behavior does not match that requirement.

## If an expected notification does not arrive
Check the notification preferences. Review the relevant application, points, or order page to confirm whether the event occurred. Do not assume a particular delivery channel or that a disabled category will generate an alert. If the website shows an event but no notification appears, contact program support.
