# Driver Notifications

## Notification types
The project requirements describe three automated driver alerts:

| Event | Can the driver disable it? |
|---|---|
| The driver is dropped by a sponsor or administrator | No; this alert must not be disableable. |
| Points are added to or removed from the driver's account | Yes; the driver may enable or disable this alert. |
| An order is placed, with an order summary | Yes; the driver may enable or disable this alert. |

## Managing preferences
If notification preferences are available:
1. Sign in as a driver.
2. Open profile, account settings, or notification settings.
3. Review the available notification options.
4. Change only the preferences the website allows you to change.
5. Save the settings if the page requires it.

[CONFIRM IN WEBSITE: Where preferences appear, delivery channel (in-app, email, or other), and whether changes take effect immediately.]

## Important exception
The alert that a driver has been dropped by a sponsor or administrator is required by the project brief to remain enabled. Do not tell drivers that they can turn this alert off.

## If an expected notification does not arrive
Check the notification preferences and the contact information on the account. Review the relevant points or order page to confirm whether the event occurred. If the website shows an event but no alert was received, contact program support.
